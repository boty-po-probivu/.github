## Бот по пробиву: как начать поиск

Начинайте с самого точного идентификатора, который у вас уже есть. Номер телефона подходит для проверки открытых упоминаний и связанных профилей, username — для поиска повторяющегося ника, а числовой Telegram ID — для проверки контекста конкретного идентификатора.

В качестве исходных данных можно использовать:

- номер телефона в полном международном формате;
- username или ник без лишних символов;
- числовой Telegram ID;
- email или ссылку на публичный профиль;
- открытую фотографию;
- ФИО и дополнительные признаки для уточнения совпадений.

## Понятный порядок проверки

1. Подготовьте один исходный идентификатор без опечаток и лишних символов.
2. Выберите соответствующий сценарий поиска в Telegram-боте.
3. Изучите прямые совпадения и связанные публичные профили.
4. Сравните даты, фотографии, описания и другие независимые признаки.
5. Повторите запрос с уточнёнными данными, если совпадение остаётся неоднозначным.

Результат зависит от доступности и актуальности открытых источников. Одинаковый ник или похожая фотография сами по себе не подтверждают личность человека.

## Как повысить точность результата

- вводите номер или username полностью и без опечаток;
- учитывайте старые usernames и возможную смену владельца номера;
- сравнивайте несколько независимых признаков;
- проверяйте дату и контекст каждого найденного упоминания;
- не считайте вероятное совпадение подтверждённым фактом.

Бот для пробива по номеру и бот для пробива по юзу решают разные задачи. Не объединяйте результаты только потому, что в них встречается похожее имя, фотография или ник.

## Частые вопросы

### Можно ли выполнить поиск по неполным данным?

Неполная строка иногда помогает найти кандидатов, но увеличивает число случайных совпадений. Для повторного запроса лучше уточнить номер телефона, username, Telegram ID или другой исходный идентификатор.

### Почему один запрос может давать разные результаты?

Публичные профили меняются, источники обновляются, а старые связи теряют актуальность. Поэтому учитывайте дату публикации и перепроверяйте связь по нескольким признакам.

### Бот открывает закрытые данные?

Нет. Материалы описывают поиск и сопоставление законно доступных открытых данных. Закрытая переписка, пароли, защищённые записи и доступ к чужим аккаунтам не входят в такой сценарий.

## Ответственное использование

Используйте поиск для проверки собственных данных, с согласия владельца или в иных законных случаях. Учитывайте приватность людей и требования применимого законодательства.
