## Бот для пробива: с чего начать

Выберите самый точный идентификатор. Номер телефона подходит для проверки открытых упоминаний и связанных профилей; username — для поиска повторяющегося ника в социальных сетях; Telegram ID — для проверки контекста числового идентификатора. Не смешивайте несколько людей в одном запросе.

Сервис направляет пользователя в Telegram-бот, где запрос выполняется по выбранному типу данных. Конкретный набор результатов зависит от доступных открытых источников и актуальности найденных связей.

## Какие данные можно использовать

- номер телефона в полном международном формате;
- username или ник без лишних символов;
- числовой Telegram ID;
- email, ссылка на профиль или открытая фотография;
- ФИО и дополнительные признаки для уточнения совпадений.

Чем точнее исходные данные, тем меньше случайных совпадений. Любой найденный результат нужно перепроверять по нескольким независимым признакам.

## Ответственное использование

Материалы предназначены для проверки собственных данных, работы с согласия владельца и других законных сценариев. Бот не предоставляет пароли, закрытую переписку или доступ к защищённым аккаунтам. Учитывайте приватность людей и требования применимого законодательства.

## Частые вопросы

### Чем пробив по номеру отличается от поиска по юзеру?

Номер является телефонным идентификатором, а username — изменяемым публичным именем. Для них используются разные источники и разные способы подтверждения.

### Что делать, если данных мало?

Начните с доступного идентификатора и используйте найденные публичные связи как уточнение. Не превращайте предположение в факт без дополнительной проверки.
